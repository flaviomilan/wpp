# Convivência

Esperamos respeito entre participantes, discussões focadas no trabalho e abertura a correções. Divergências técnicas são bem-vindas; assédio, discriminação, ameaças, exposição de dados privados e ataques pessoais não são aceitos.

O responsável pela moderação do projeto é [Flávio Milan (@flaviomilan)](https://github.com/flaviomilan), mantenedor de [flaviomilan/wpp](https://github.com/flaviomilan/wpp). Ele pode moderar comentários, pedir mudanças de conduta e restringir participação para proteger a comunidade. Decisões devem ser proporcionais ao ocorrido e respeitar a privacidade de quem relata um problema.

## Como relatar

Para comentários, issues ou pull requests, use o menu **… → Report content**. Quando aparecer **Report to repository admins**, o relato vai aos administradores do repositório. A disponibilidade dessa opção depende da configuração do repositório e é conferida antes da publicação.

Se essa opção não aparecer, ou se o problema envolver o mantenedor, use **Report abuse to GitHub Support** ou o [formulário privado de abuso do GitHub](https://support.github.com/contact/report-abuse). Nesse caso, quem recebe o relato é a equipe do GitHub, não o mantenedor. O envio não cria uma issue pública. Informe os links do conteúdo e somente as evidências necessárias; não publique dados pessoais para relatar uma violação.

Consulte as [instruções oficiais para denunciar abuso](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Esses canais existentes dispensam publicar e-mail pessoal. Problemas comuns podem usar Issues sem dados sensíveis; vulnerabilidades do software seguem o canal separado de [SECURITY.md](SECURITY.md).

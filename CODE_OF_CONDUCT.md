# Code of conduct

Treat participants respectfully, keep discussions focused on the work, and remain open to corrections. Technical disagreement is welcome. Harassment, discrimination, threats, disclosure of private information, and personal attacks are unacceptable.

[Flávio Milan (@flaviomilan)](https://github.com/flaviomilan), maintainer of [flaviomilan/wpp](https://github.com/flaviomilan/wpp), is responsible for moderation. He can moderate comments, request conduct changes, and restrict participation to protect the community. Decisions must be proportionate and respect reporters' privacy.

## Reporting

For comments, issues, or pull requests, use **… > Report content**. When available, **Report to repository admins** sends the report to repository administrators. Availability depends on repository configuration and is checked before publication.

If that option is unavailable or the issue involves the maintainer, use **Report abuse to GitHub Support** or [GitHub's private abuse form](https://support.github.com/contact/report-abuse). GitHub's team receives that report rather than the maintainer; submission does not create a public issue. Include content links and only necessary evidence. Never disclose personal information to report a violation.

See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). These channels avoid publishing a personal email. Ordinary issues must omit sensitive data; software vulnerabilities use the separate channel in [SECURITY.md](SECURITY.md).
